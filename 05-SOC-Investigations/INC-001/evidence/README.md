# INC-001 — Authentication Investigation Evidence

This directory contains supporting screenshots from a
controlled Windows authentication failure investigation
conducted in an isolated Active Directory lab.

| Screenshot | Description |

## Evidence Handling

will be published. Original Security event exports
remain private.

This was a controlled simulation, not a real-world attack.
